# Chemille® B2B Website Redesign, Celanese — UX case study

A static case study of **Ravi Myneni's** shipped redesign of the **Chemille®** B2B website for Celanese, [askchemille.com](https://www.askchemille.com/), aligned to the Celanese Design System. It covers guided AI grade search and competitor-grade replacement. By [Ravi Myneni](https://www.linkedin.com/in/ravimyneni/), Sr UX Designer at Celanese.

The redesign is live. The Metrics section reports its measured results: 22% higher customer retention, 17% more lead conversions, a 13% uplift in international revenue, and, from the personalized dashboard, 30% less time per procurement session, 20% more repeat transactions and 28% higher client satisfaction.

## View it

Published with GitHub Pages from the repository root:

https://ravimyneni.github.io/askchemille-case-study/

Locally, open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8080
```

Then visit http://localhost:8080/. Paths are relative, so the site works both as a project site and from a local folder.

There is no build step. The page is plain HTML and CSS (`case-study.css`), plus a small script for the image viewer. Diagrams are inline SVG. An empty `.nojekyll` file keeps Jekyll from processing the site.

## What the study claims

Role: Sr UX Designer at Celanese, covering UX audits, heuristic evaluation, IA, interaction design and UI, aligned to the Celanese Design System, working with product managers and chemists. Research includes a heuristic evaluation (Nielsen's 10), cognitive walkthroughs and task analysis of the desktop screens. Personas are proto-personas. The metrics are measured results of the shipped redesign.
